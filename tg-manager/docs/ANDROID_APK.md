# Infragram на Android: PWA и готовый APK

Владелец хотел работать с телефона не только через интерфейс Telegram. Сделано:
автономный вход + два способа поставить приложение — PWA и настоящий `.apk`.

## Как это входит без Telegram

Мини-апп раньше пускал только через Telegram (`initData`). Отдельное приложение
так войти не может, поэтому добавлено **связывание устройства** с той же точкой
доверия — ботом:

1. в боте команда **/pair** выдаёт одноразовый код (живёт 5 минут);
2. приложение меняет код на **токен устройства** (хранится на телефоне ~30 дней);
3. приложение меняет токен устройства на обычный сессионный токен — дальше всё
   работает как в Telegram-мини-аппе.

Управление устройствами — `GET /api/miniapp/devices`, `POST /api/miniapp/devices/revoke`.
Сам токен на сервере не хранится — только его отпечаток (sha256).

## Способ 1 — готовый файл .apk (нативная обёртка WebView)

Проект — `android/` (Java + WebView, без Telegram-зависимостей). Один и тот же
APK годится для любого сервера: **адрес вводится в приложении при первом
запуске**, домен при сборке не нужен.

Установка на телефон:
1. Открыть присланный `Infragram.apk` на Android → «Установка из этого
   источника».
2. Первый запуск → ввести адрес сервера (домен из `MINI_APP_URL`; `/miniapp`
   добавится сам).
3. В боте отправить **/pair**, ввести код — приложение войдёт и дальше входит
   само.
4. Адрес и обновление — в меню (⋮): «Обновить», «Изменить адрес сервера».

Пересборка (например, после правок): GitHub → **Actions** →
**build-android-apk** → **Run workflow** → скачать `infragram-apk` из Artifacts.
Собирает `android/gradlew :app:assembleRelease` на раннере с Android SDK.

Локальная сборка:
```bash
cd android
ANDROID_SDK_ROOT=/путь/к/android-sdk ./gradlew :app:assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

Подпись сейчас — **отладочным ключом** (APK ставится sideload'ом). Для стабильных
обновлений и публикации подставьте свой release-keystore в `app/build.gradle`
(`signingConfigs`) и храните его в секретах CI.

## Способ 2 — PWA (без файла, установка из Chrome)

1. Открыть на Android в **Chrome**: `https://ВАШ-ДОМЕН/miniapp/`.
2. Меню (⋮) → **«Установить приложение»** → иконка на экране, полноэкранный режим.
3. Дальше тот же вход по коду `/pair`.

PWA-часть: `mini_app/manifest.webmanifest`, `sw.js`, иконки; регистрация SW в
`index.html`.

## Мелочи

- `/.well-known/assetlinks.json` отдаётся из переменной `ANDROID_ASSETLINKS`
  (нужно только если позже делать TWA без адресной строки; для WebView-APK не
  требуется, без переменной — 404, это норма).
