# docs/CLAUDE.md

Правила агента разнесены на два файла (здесь не дублируем, чтобы не было расхождений):
- **`../CLAUDE.md`** (корень `tg-manager/`) — костяк: язык, жёсткие гейты, load-bearing
  проектные факты, указатели. Читается каждую сессию.
- **`AGENT_PROTOCOL.md`** — полная детализация: режим работы, класс Fable 5/Mythos,
  мультиагентность, классы багов, прод-безопасность массовых операций, недоверенный
  ввод, проверка, критерий готовности и эскалация.

Смежные стандарты (ориентир, не гарантия текущего состояния кода):
`WORKING_STANDARD.md`, `QUALITY_STANDARD.md`, `SECURITY.md`, `TESTING.md`,
`RELEASE_GATES.md`, `DATABASE.md`, `API.md`, `UI_GUIDELINES.md`.

Журнал памяти между сессиями — `AUDIT_LEDGER.md`.
