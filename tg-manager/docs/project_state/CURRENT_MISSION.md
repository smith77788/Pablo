# Текущая миссия

**Статус:** ACTIVE · **Обновлено:** 2026-09-04

## Миссия

Доводить модули Infragram до состояния, в котором ими пользуются, а не «оно
вроде есть». Один модуль за раз, до предела, потом следующий.

Не планирование. Не аудит ради аудита. Работающий продукт.

## Как выбирается следующий модуль

Берётся 1–2 связанных модуля и разбираются целиком по цепочке
**пользователь → интерфейс → настройки → валидация → бэкенд → база → исполнение
→ результат → ошибка → восстановление → аудит → обратная связь**. Слабое звено в
любом месте цепочки означает, что модуль ещё не готов.

Модуль считается закрытым, только когда систематически проверен со всех сторон и
существенных улучшений в рамках текущих технологий больше не находится. Не
«тесты зелёные» и не «основное работает».

**INVITING** (2026-09-04) — разобран целиком. Из найденного: ложный тупик второй
кампании (фильтры применялись ПОСЛЕ усечения источника), мёртвый ретеншен
(маркер `joined` не писал никто), безымянная корзина отказов «прочее»,
неработающая настройка темпа, мёртвая валидация ссылки на чат, регистрозависимый
дедуп, метод «ссылка в ЛС», рассылавший одинаковый текст всем. Подробности — в
истории коммитов с префиксом «Инвайт:».

## Следующее

Модуль не выбран. Кандидаты по убыванию отдачи:

1. **Рассылки / DM-кампании** — параллельно правились другим агентом, стоит
   пройти той же методикой и свести;
2. **Аккаунты: импорт, прогрев, восстановление** — самый частый вход
   пользователя и самый частый источник «не работает»;
3. **Парсер аудитории** — питает инвайт и рассылки; его качество определяет их
   конверсию.
