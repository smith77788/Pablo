# Quality Standard — Стандарт качества

## Стабильность
- 99.9% операций завершаются успешно
- 0 крашей op_worker за сутки
- <1% ошибок proxy
- 0 зависших операций >24 часа

## UX
- Response time <500ms (API), <2с (Mini App)
- 0 тупиков в навигации
- 100% экранов с Cancel/Back кнопками
- Live-обновления через SSE каждые 15сек

## Интеллект
- Автоматический выбор прокси
- Предсказание банов >80% точность
- Auto-tuning на основе истории
- Smart Presets для strike

## Производительность
- Mass operations: >100 аккаунтов/час
- DB queries: <100ms (95-й перцентиль)
- Cache hit rate: >70%
