# Быстрый вход Google для почтовых подключений

Экран: Интеграции → Почтовые ящики → Войти через Google.
Это разрешение на доступ к своей почте, а не авторизация в аккаунт Infragram.
Один подключённый ящик принадлежит только текущему владельцу Infragram.

## Настройка

1. Зарегистрируйте OAuth-клиент типа Web application в Google Cloud.
2. Настройте экран согласия и аудиторию приложения. В тестовом режиме добавьте
   пользователей в разрешённую тестовую аудиторию.
3. Зарегистрируйте точный HTTPS Redirect URI:
   `https://<публичный-домен-приложения>/oauth/email/callback`.
4. Задайте в Railway `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`,
   `EMAIL_OAUTH_REDIRECT_URI` и независимый случайный `EMAIL_OAUTH_STATE_SECRET`.
   Для хранения токенов нужен стабильный `TOKEN_ENCRYPTION_KEY`.
5. Перезапустите сервис. Кнопка входа станет доступной после настройки ключей.

Для существующей SMTP/XOAUTH2-отправки запрашивается разрешение
`https://mail.google.com/` вместе с идентификацией пользователя. Публичное
использование такого разрешения может требовать проверки приложения Google.
Нельзя заменять его простым входом с email/profile: он не разрешает отправку почты.

## Проверка

- Вход открывается в браузере Google. Не вводите пароль Google в Infragram.
- После согласия возвращается русская страница результата. Вернитесь в мини-апп
  и нажмите «Обновить список».
- Отказ пользователя и ошибка провайдера не создают подключение.
- Токены не возвращаются в API мини-аппа и шифруются при сохранении.
- OAuth не отменяет ограничения исходящего SMTP Railway или политики Google.
  Успешное подключение не подтверждает доставку какого-либо письма.
- Microsoft не включён в быстрый вход мини-аппа: существующую интеграцию бота
  нужно отдельно проверить на корректные SMTP-разрешения перед её включением.
