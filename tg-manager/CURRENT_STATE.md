# Текущее состояние

Обновлено: 2026-09-04

## Коротко

| | |
|---|---|
| Продукт | Infragram — Telegram-инфраструктура и массовые операции |
| Код | `tg-manager/` (~285 тыс. строк Python) |
| Ветка | `claude/telegram-bot-services-xfAh6`, с неё автодеплой |
| Тесты | ~4550, полный прогон ~3 мин, CI по `tg-manager/**` |
| Процесс | Один: бот + HTTP + ~50 фоновых циклов. `INFRAGRAM_ROLE` умеет `all/web/worker` |

## Что работает

Ядро операций: шина `operation_bus` с реестром 72 типов, гейтом тарифа,
предохранителем Ban Weather и дедупом; исполнитель `op_worker` с таблицей
исполнителей; адаптивный пейсинг с предохранителем; иммунитет флота с
сигнатурами смерти; граф контактов (`contacts_hub`); шина событий «организма».

Поверхности: бот (103 роутера) и мини-апп (500 маршрутов). Мини-апп — строгое
подмножество бота: 175 сервисов против 203.

## Ограничения, о которых надо помнить

- **Одна реплика исполнителя.** Лимиты флуда в памяти процесса; вторая реплика
  молча разгонит темп по флоту. `web`+`worker` разносить безопасно, два
  `worker` — нет.
- **194 файла схемы.** Обновление их пропускает по журналу `schema_migrations`,
  но чистая база прокатывает всю историю. Baseline готов, снимок не снят.
- **Транспорт прибит к Telethon.** 47 сервисов работают с ним напрямую.
- **Business API есть только в «Хранилище»** — подписка на бизнес-апдейты
  работает, транспортом для автоматизаций он не сделан.
